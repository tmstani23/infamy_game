# Image prompts

Saved prompts for Gemini / ChatGPT, copied word for word from the chat with Tim.

## How to keep the style consistent

- Attach the matching earlier image as a reference: **hero1.png** for characters, **buildings1.png** for buildings and props, **textures1.png** for textures. Then paste the saved prompt below with the changes you want.
- Shared style keywords:
  - 1870s Japan
  - Dota 2 base with anime touches (never name a game in a prompt; Gemini refuses)
  - cool and sleek
  - muted and moody, not bright, boxy or dull
  - buildings and props: isometric 2:1 angle, same lighting every time
  - textures: top-down, seamless tiles
