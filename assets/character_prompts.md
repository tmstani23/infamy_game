# Character prompts

How to use: attach **hero1.png** as the style reference, paste one prompt, and save the result under the file name shown. Then make the 3D model on Tencent.
Done already: ronin (hero1.png), mercenary (mercenary1.png), brute (brute1.png); their prompts are in `image_prompts.md` (Characters).

Every prompt has the same opening and ending. Only the description in the middle changes.

## Heroes

**Ninja clan leader**: `ninja_hero1.png` (accent: deep indigo)
```
Using the attached image as a style reference, make a full-body character concept of a ninja clan leader in 1870s Japan for a dark, stylized game, sleek and not cartoony. A lean, agile build in a dark charcoal and deep indigo shinobi outfit with fitted wrappings, a hood and a cloth mask showing only the eyes, a short tattered scarf, light armor plates on the forearms and shins, and tabi boots. Front view, standing straight in an A-pose with the arms held slightly away from the body and the legs slightly apart, nothing in the hands and no weapons. On a transparent background (if true transparency is not possible, a flat solid single-colour background with no shadow, gradient or checkerboard pattern), even lighting, muted and moody colors. Keep the exact same art style, rendering, level of realism, lighting, textures and detail as the attached image; do not restyle it or make it flatter or more cartoony.
```
