# Usage rules

Rules for Claude threads working on this project, to keep usage low (agreed with 2026-10-16).

- **Testing:** quick Node checks of the sim (`game/src/sim`) only. No headless-browser or Playwright runs, no screenshots. checks the look in his own playtests.
- **Preview renders:** keep them to a minimum.
- **Replies:** only for results and blockers.
- **Project chat:** relays only blockers and finished results, no progress updates.
- **Threads:** close a thread as soon as its work is finished.
- **Models:** every new thread runs at least Opus medium (2026-11-20).
- **Big builds:** go in phases with a checklist in the plan file, ticked off as each phase lands, so work survives if usage runs out.
- **Sound credits (2026-11-23):** ElevenLabs Starter (30k credits) bought 2026-11-23 for one month, renewal cancelled, ends around 2026-12-23. Batch sound generation before then.
